FAQ

Questions answered.

Which cameras are supported? +
Any camera that records to MP4 files. This includes TP-Link Tapo, Reolink, Xiaomi, Hikvision, dashcams, baby monitors, and virtually any security or surveillance camera. If it saves .mp4 files to an SD card or folder, ClipKeepr can process it.
Does it delete files automatically? +
No. ClipKeepr never deletes anything. Static files are moved to a _STATIC_REVIEW subfolder where you can inspect them before deciding to delete. Motion files stay exactly where they are.
Is my footage safe? Does it upload anything? +
Completely safe. ClipKeepr runs 100% locally on your PC. Your video files never leave your computer. No internet connection is required after download.
How fast is it? +
Very fast. ClipKeepr uses parallel processing and analyzes videos at a reduced resolution to maximize speed without affecting accuracy. A typical 16,000-file batch processes in roughly 30–60 minutes depending on your hardware.
What does the sensitivity slider do? +
The slider controls how much pixel change counts as "motion." Lower = more sensitive (catches subtle movement like breathing or slow pans). Higher = only flags significant activity like walking or objects moving. The log shows the exact % for each file so you can calibrate it perfectly.
What's the difference between Free and Pro? +
The Free version lets you run unlimited dry runs (analysis without moving files) and includes 50 live processing runs. The Pro version removes this limit entirely — unlimited live processing forever, for a one-time $12 payment.
